# CyberControl frontend

Operator web app (cafe UI), landing site, and the in-app file viewer/print tools.

## Getting started

```sh
pnpm install
pnpm typecheck
pnpm test
```

Working rules and the package list are in [AGENTS.md](AGENTS.md).

## Needing something from another department

Open an issue that describes the contract you need (inputs, outputs, errors). Do not copy their code.
